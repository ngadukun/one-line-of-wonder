A program that prints exactly one line — a single sentence built to produce
genuine wonder. It rests on a true scale shift: the hydrogen in a human body
is primordial. Those atoms formed in the first minutes after the Big Bang,
before any star ignited, and hydrogen nuclei are effectively indestructible
on cosmic timescales — the matter in you predates the Sun and will outlast it.

## The entry

> Nearly every hydrogen atom in your body is older than the Sun, older than the Earth, older than every star you can see — a spark from the universe's first minutes that will still exist when all of them are gone.

## Run it

```sh
python3 main.py
```
